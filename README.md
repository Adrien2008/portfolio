# Portfolio d'Adriano

Site statique (HTML, CSS, JavaScript). Pas de build, pas d'installation.

## Avant de mettre en ligne

1. Ouvre `config.js` et remplis ton numéro WhatsApp (format `237XXXXXXXXX`), ton e-mail et, si tu en as un, ton LinkedIn. Une valeur vide cache le bouton.
2. Les captures de HorizonApp sont déjà dans `assets/` (`horizonapp-1.png` et `horizonapp-2.png`).
3. Ouvre `index.html` dans ton navigateur pour vérifier.

## Mettre sur GitHub (sans token)

1. Sur github.com, clique sur **New repository**, nomme-le `portfolio`, public.
2. Clique sur **uploading an existing file**.
3. Glisse tout le contenu du dossier (index.html, style.css, script.js, config.js, favicon.svg, dossier assets). Puis **Commit changes**.

## Mettre en ligne avec Vercel

1. Sur vercel.com, **Add New > Project**, choisis le dépôt `portfolio`.
2. Framework Preset : **Other**. Ne change rien d'autre, clique sur **Deploy**.
3. Tu obtiens un lien du type `portfolio-xxxx.vercel.app`. Ajoute-le dans ton CV, ton profil GitHub et tes messages WhatsApp.

Chaque modification envoyée sur GitHub met le site à jour automatiquement.
