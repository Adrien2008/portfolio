01Projets

Application de gestion, web et mobile

HorizonApp

Une plateforme de gestion pour une PME : ventes, stock, impressions et formations. Réalisée en 7 jours pour un test technique de recrutement, puis enrichie d'un module d'impressions.

  • 4 rôles (super admin, vendeur, agent d'impression, formateur), chacun avec son propre accès
  • Point de vente avec facture en PDF, alerte de stock bas et export CSV des ventes
  • Suivi des commandes d'impression, de « en attente » à « livré »
  • Formations avec présences et attestation en PDF
  • Laravel 12
  • React
  • Tailwind CSS
  • MySQL
  • Sanctum
  • Flutter

Météo

Une application météo simple et rapide. On cherche une ville ou on utilise sa position, et on voit tout de suite le temps qu'il fait.

  • Recherche de ville et géolocalisation
  • Conditions du moment : température, ressenti, indice UV, humidité, vent
  • Prévisions sur 7 jours
  • Interface en français, pensée pour le téléphone
  • Application web
  • API météo
